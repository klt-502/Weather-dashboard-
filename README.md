# Richmond 14-Day Weather

A mobile-friendly forecast chart for Richmond, Indiana.

- 14-day high/low temperature graph in °F
- Daily precipitation probability bar (blue), overcast/dry days (gray), clearer/dry days (yellow)
- Weekend shading and refresh button
- Open-Meteo API, no API key required

## Publish via GitHub Pages

1. In repository Settings → Pages, choose **Deploy from a branch**.
2. Select `main` and `/ (root)`, then click **Save**.
3. The site URL will be `https://klt-502.github.io/Weather-dashboard-/`.

After it loads in Chrome on Android, select the three-dot menu → **Add to Home screen**.

This is a public site; it contains only a hardcoded forecast location and no personal account credentials. Internet connection required to retrieve updates.
